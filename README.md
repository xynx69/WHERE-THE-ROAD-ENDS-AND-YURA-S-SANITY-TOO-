# WHERE-THE-ROAD-ENDS-AND-YURA-S-SANITY-TOO-
Yura went for a chill forest meetup, not a low-budget Resident Evil. Lost with no signal, he must scavenge ammo off stumps, dodge leg-bitten locals, fight off a stick-wielding beaver, and survive a giant bear—all while chasing romantic hallucinations of Ulyana that hurt worse than his concussion. Help Yura reach the hospital before Mom worries!
